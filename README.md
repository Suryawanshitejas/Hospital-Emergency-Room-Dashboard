# 🏥 Hospital Emergency Room Dashboard (End-to-End Excel Project)

## 📌 Project Overview  
This project is an **End-to-End Data Analytics Dashboard** built using **Microsoft Excel**.  
It analyzes Hospital Emergency Room (ER) data to provide insights into patient flow, wait times, and overall service efficiency.

The goal of this project is to transform raw healthcare data into **interactive visualizations** that help in better decision-making.

---

## 🎯 Why I Built This Project  
Emergency Rooms often struggle with:  
- Long patient wait times  
- Inefficient resource allocation  
- Lack of data-driven insights  

👉 This project was built to:  
- Analyze patient flow  
- Identify delays in treatment  
- Improve hospital operational efficiency  
- Demonstrate real-world use of data analytics  

---

## 🛠️ Tools & Technologies Used  
- **Microsoft Excel** – Dashboard Development  
- **Power Query** – Data Cleaning & Transformation  
- **Power Pivot** – Data Modeling  
- **DAX** – Business Calculations  
- **Excel Charts** – Data Visualization  

---

## 🔄 End-to-End Workflow  
1. Business Requirement Gathering  
2. Data Understanding  
3. Data Import using Power Query  
4. Data Cleaning & Preprocessing  
5. Calendar Table Creation  
6. Data Modeling (Power Pivot)  
7. DAX Calculations  
8. Pivot Tables Creation  
9. Dashboard Design  
10. Insights Generation  

---

## 📊 Dashboard Features  
- 📈 Total Number of Patients  
- ⏱️ Average Wait Time Analysis  
- ⭐ Patient Satisfaction Score  
- 🏥 Admission vs Non-Admission  
- 👥 Patient Distribution by Age Group  
- 🚻 Gender Analysis  
- 📌 Department Referral Insights  
- ⏳ Timeliness (Within 30 Minutes vs Delay)  

---

## 💡 Key Insights  
- Majority of patients fall in the **30–44 age group**  
- Around **61% patients attended on time**  
- High referrals in **General Practice & Orthopedics**  
- Balanced admission and non-admission ratio
